## 制作流程

1. TTS 生成音频 → `public/content/seg-xx.mp3`
2. 数字人工作台：上传音频生成视频 → `public/content/seg-xx.mp4`
3. 确认 `data/lessons/sat-math-quadratic-01.json` 中各 segment 的 `avatarVideoUrl` 路径正确
4. `npm run dev` → 打开 `/lesson/sat-math-quadratic-01` 验证

> **注意**：所有直播触发点均位于录播段边界处，视频不会被中途打断。
